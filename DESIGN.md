# Rocket Simulator

## Goal

Develop a 2D rocket simulator in C++ using SFML.

The simulator should allow the player to modify rocket parameters before launch and observe a realistic flight based on physics.

---

## Features

- Adjustable rocket mass
- Adjustable fuel
- Adjustable thrust
- Gravity
- Air resistance
- Fuel burn
- Launch sequence
- Camera follows rocket
- Flight telemetry
- Crash detection
- Explosion effects
- Restart simulation
